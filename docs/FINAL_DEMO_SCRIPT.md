## 0:00 — Problem (30 sec)
"Traditional RS analysis requires specialist GIS operators. SatQuery AI lets any analyst ask natural language questions about optical, SAR, or multi-modal imagery and get scientifically grounded answers with full evidence and audit trail."

## 0:30 — Architecture (30 sec)
"An agentic pipeline: query enters the SatQuery Agent, validates inputs, selects a specialist tool, runs deterministic raster analytics, then sends evidence to Qwen2-VL for interpretation. The answer cites evidence rather than guessing."

## 1:00 — FLOW 1: Single Optical VQA (75 sec)
Upload: landsat7_rgb_sample.tif
Verify: Modality = RGB shown in asset panel
Query: "What does this satellite image show?"
Show: Answer, provenance showing LoRA adapter loaded, execution trace

"The model is Qwen2-VL-2B fine-tuned with a remote-sensing LoRA adapter. On CPU this takes 60-90 seconds. On GPU it is significantly faster."

## 2:15 — FLOW 2: Bi-Temporal Change (90 sec)
Upload: landsat7_rgb_t2_simulated.tif as second asset
Select both assets
Query: "What changed between these two images?"
Show: changed_pixel_count (exact integer), change_fraction, region count
Demonstrate: changed_pixel_count / valid_pixel_count = change_fraction exactly

"100% deterministic — co-registered raster differencing using rasterio. These numbers are NOT generated by AI. The VLM only interprets what the analytics found."

## 3:45 — FLOW 3: SAR Analysis (60 sec)
Upload: simulated_sar_sample.tif
Verify: Modality = SAR (detected from VV polarization metadata)
Query: "What are the strongest backscatter regions?"
Show: p99 dB, spatial region bounding boxes
Emphasize safe language: "high-backscatter region" NOT "confirmed building"

"Note: this is a SAR simulation derived from Landsat to guarantee offline demo availability. The pipeline handles real Sentinel-1 GRD products identically."

## 4:45 — FLOW 4: Optical + SAR Cross-Modal (60 sec)
Select optical T1 + SAR assets
Query: "Compare the optical and SAR evidence."
Show: bbox_iou value, relationship classification (AGREEMENT/DISAGREEMENT/etc)
Emphasize: "We call this Bounding-Box IoU — explicitly NOT pixel-mask IoU. Agreement means spatial corroboration, not ground truth confirmation."
